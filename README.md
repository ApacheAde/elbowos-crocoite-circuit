# Crocoite Circuit

Full-colour Python 3 neon light-cycle arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a cyan rider across a portrait grid.
Leave a glowing trail.
Collect orange crocoite shards.
The magenta rival hunts the same lanes — crash into a wall or a trail and the circuit resets.

WASD / arrows steer. R resets.

## Play

```
pip install -r requirements.txt
python3 crocoite_circuit.py --play
```

## Record a 9:16 reel

```
python3 crocoite_circuit.py --record
```

Writes `/home/workdir/artifacts/CROCOITE_CIRCUIT_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264).
